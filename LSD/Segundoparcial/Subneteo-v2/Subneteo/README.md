# Calculadora de Subneteo IPv4

Página web para resolver ejercicios de subneteo de redes IPv4.

## Secciones
1. **Decimal a binario**: convierte un octeto o una IP con el método de restas.
2. **FLSM**: divide una red en subredes iguales, por número de subredes o por hosts.
3. **VLSM**: asigna a cada área el bloque más pequeño que le alcanza.
4. **¿A qué red pertenece?**: calcula red, rango de hosts y broadcast (IP AND máscara).

## Archivos
```
index.html          Estructura de la página
css/estilos.css     Diseño
js/calculos.js      Lógica del subneteo (objeto Red)
js/interfaz.js      Formularios y resultados
```
